# Sumaia Afroz Sayka — Engineering & Research Portfolio

Live link: https://saykaportfolio.vercel.app/

A minimalist, editorial-grade developer and researcher portfolio built with **Next.js**, **React**, and **Tailwind CSS** — the same modern stack used for the Dhaka Sessions Scheduler platform.

## ✨ Highlights
- **Minimal & Classy Design:** Warm alabaster (`#FAF9F6`) light theme and deep obsidian (`#0D0F12`) dark theme with refined `Playfair Display` + `Inter` + `JetBrains Mono` typography.
- **Filterable Engineering Projects:** Showcases *MindWell*, *Dhaka Sessions Scheduler*, *FlowMaster*, *CPU Scheduling Simulator*, and *C++ OOP Projects*.
- **Research & Speaking Spotlight:** Highlights the accepted **IEEE SPICSCON 2026** paper (*MELT: Multilingual Ethnic Language Translator for the Marma Language*) and ULAB invited workshop.
- **Interactive Printable CV (`/cv`):** Dedicated print-ready CV route with one-click **Save as PDF**.

## 🚀 Getting Started

Open a terminal inside `E:\Portfolio` and run:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
